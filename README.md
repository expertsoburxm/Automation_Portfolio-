# GoHighLevel Automation Portfolio — AbdSobur

A single-page portfolio showcasing a lead capture and nurture system built in GoHighLevel: form submission → automated email/SMS follow-up → booked appointment or converted opportunity.

## View it live

Once GitHub Pages is enabled (see below), this site will be live at:

```
https://<your-github-username>.github.io/<repo-name>/
```

## How to host this on GitHub Pages

1. Create a new repository on GitHub (e.g. `gohighlevel-portfolio`).
2. Upload everything in this folder — `index.html` and the `images/` folder — to the root of that repo.
   - Easiest way: on the repo page, click **Add file → Upload files**, then drag in `index.html` and the `images` folder together, and commit.
3. Go to the repo's **Settings → Pages**.
4. Under "Build and deployment," set **Source** to `Deploy from a branch`.
5. Set **Branch** to `main` and folder to `/ (root)`, then click **Save**.
6. Wait 1–2 minutes, then refresh — GitHub will show your live URL at the top of the Pages settings.

## Files

- `index.html` — the whole page (structure, styling, and copy all in one file)
- `images/` — the four workflow screenshots referenced by the page

## Updating content

All the text lives directly in `index.html` — open it in any text editor, find the section you want to change, and edit the text between the tags. No build step is required; GitHub Pages serves the HTML file as-is.
